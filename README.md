# Landing de Mauro Cuevas

Archivo principal: `index.html`. Incluye la landing, la comunidad, imágenes, fuentes y estilos. La vista de comunidad se abre con `#/comunidad`.

Publicación: rama `main` de este repositorio, conectada a Render.
URL: https://landing-mauro-cuevas.onrender.com

Guardar un cambio local no publica la web: hay que hacer commit y push, y verificar el despliegue de Render.
